- Чтобы создать ветку, нужно ввести команду git branch <название ветки>
- Чтобы переключиться на ветку, нужна команда git checkout <название ветки>
- Чтобы соединить 2 ветки необходимо перейти в ту, в которой должен быть результат объединения и использовать команду git merge <название ветки, с которой необходимо объединение>
